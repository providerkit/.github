[providerkit](https://github.com/providerkit/providerkit) te permite llamar a modelos de IA desde TypeScript sin reescribir tu código para cada proveedor. Tú decides qué hace tu agente.

- Detecta respuestas que dejan de llegar y decide cuándo reintentar o cambiar de modelo.
- Distingue los fallos temporales de los límites de la cuenta y las conversaciones demasiado largas.
- Consulta el uso y el costo en el mismo formato entre proveedores.

No necesita otros paquetes para funcionar. Funciona en Node 22+, Bun, Deno, Cloudflare Workers y extensiones de Chrome.

```sh
bun add @providerkit/core
```
