O [providerkit](https://github.com/providerkit/providerkit) permite chamar modelos de IA em TypeScript sem reescrever seu código para cada provedor. Você continua decidindo o que seu agente faz.

- Detecte respostas que pararam de chegar e decida quando tentar de novo ou trocar de modelo.
- Diferencie falhas temporárias de limites da conta e conversas longas demais.
- Consulte uso e custo no mesmo formato entre provedores.

Não precisa de outros pacotes para funcionar. Roda em Node 22+, Bun, Deno, Cloudflare Workers e extensões do Chrome.

```sh
bun add @providerkit/core
```
