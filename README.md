# providerkit on GitHub

GitHub reads this repository to display the [organization profile](https://github.com/providerkit).

Edit the English, Portuguese and Spanish pages in [`providerkit/providerkit/brand/profile`](https://github.com/providerkit/providerkit/tree/main/brand/profile), not here. After they merge, run `bun run profile:pr` in the monorepo. Merge the resulting PR here to publish all three pages together.

The profile loads the mark from the monorepo. The avatar and repository share card are separate GitHub settings. See the [brand instructions](https://github.com/providerkit/providerkit/tree/main/brand#github-organization-profile).
